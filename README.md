## ❗ Sobre o Projeto

Esse repositório contém o front-end do projeto **TC Ateliê**, uma aplicação de e-commerce desenvolvida com foco em performance e experiência do usuário. Os usuários podem cadastrar produtos, adicionar personalizações, editar informações e futuramente realizar pedidos.

## 📦 Instalação

```bash
# 1. Clone o repositório
git clone https://github.com/grupo-04-3adsb/e-commerce-frontend

# 2. Acesse a pasta
cd ecommerce-tc-atelie

# 3. Instale as dependências
npm install

# 4. Execute o projeto
npm run dev
```

Depois, acesse em: [http://localhost:5173](http://localhost:5173)

---

## 🛠️ Funcionalidades

- ✅ Cadastro de produtos com imagem e descrição  
- ✅ Adição de personalizações (nome, cor, imagem)  
- ✅ Interface reativa e responsiva  
- 🚧 Integração com API em desenvolvimento  
- 🚧 Autenticação de administrador

## 📁 Estrutura de Pastas

```bash
src/
├── assets/             # Imagens e arquivos estáticos
├── components/         # Componentes reutilizáveis
├── forms/              # Formulários de produto e personalização
├── pages/              # Páginas principais do app
├── viewmodels/         # Lógica e estados centralizados
└── App.jsx             # Componente raiz da aplicação
```
